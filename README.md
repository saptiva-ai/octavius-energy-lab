# Octavius Energy Lab

Laboratorio open source para evaluar *agent harnesses* sobre Octavius, con datos eléctricos de CENACE y Low Carbon London, un LLM local (Qwen3-8B) y forecasting con TimesFM.

Charla: **Beyond the Model: The Art of Evaluating Agent Harnesses** (Cloud Community).

> Do not optimize the benchmark to make the harness look good. Design the benchmark to reveal where the harness actually fails.

## Estado

Fase 0 (discovery y diseño). Todavía no hay código.
